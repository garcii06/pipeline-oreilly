# O'Reilly Learning Pipeline

A data engineering portfolio project that answers a simple business question:

> **What tech topics are trending over time on O'Reilly Learning?**

This pipeline ingests content data from the O'Reilly Search API, stores and transforms it through a Medallion architecture, and produces a monthly topic trend dataset ready for analysis.

---

## The Problem

O'Reilly publishes thousands of books, videos, and courses across hundreds of tech topics. Understanding which topics are growing in content volume and engagement over time is valuable for learners, publishers, and content strategists alike. This pipeline automates that data collection and transformation on a daily schedule.
